
Kazakhstan Road Accident Analysis
Overview
This project presents a statistical analysis of road traffic accidents across regions of Kazakhstan.
The objective of the study was to identify factors associated with accident frequency and evaluate relationships between demographic, economic, and transportation indicators.
The analysis was performed using Statistica and Microsoft Excel.
Dataset
The dataset contains information from regions of Kazakhstan and includes:
* Number of road traffic accidents
* Population
* Number of passenger vehicles
* Average income
* Vehicle age
* Road network characteristics
* Freight turnover
Methods Used
* Descriptive Statistics
* Correlation Analysis
* Simple Regression
* Multiple Regression
* Factor Analysis
* General Linear Models (ANOVA)
* Cluster Analysis
Key Findings
* Population size was identified as one of the strongest factors associated with accident frequency.
* Vehicle-related indicators also demonstrated significant relationships with accident occurrence.
* Statistical models were used to evaluate the influence of multiple factors simultaneously.
Tools
* Statistica
* Microsoft Excel
